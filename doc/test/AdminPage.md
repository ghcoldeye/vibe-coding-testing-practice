## [x] 【前端元素】渲染管理後台標題與特色清單

## [x] 【前端元素】渲染角色標籤與登出按鈕
**範例輸入**：`user` 為 `{ username: 'AdminUser', role: 'admin' }`
**期待輸出**：畫面上方顯示角色標籤「管理員」，並顯示「登出」按鈕。

## [x] 【function 邏輯】點擊返回連結導向 /dashboard
**範例輸入**：點擊「← 返回」連結
**期待輸出**：路由導向至 `/dashboard`。

---

## [x] 【function 邏輯】點擊登出按鈕時呼叫 logout 並導向 /login
**範例輸入**：點擊「登出」按鈕
**期待輸出**：呼叫 `logout()`，並使用 `navigate('/login', { replace: true, state: null })` 進行路由導向。
