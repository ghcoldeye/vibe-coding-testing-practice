## [x] 【前端元素】渲染歡迎使用者與角色標籤
**範例輸入**：`user` 為 `{ username: 'TestUser', role: 'user' }`
**期待輸出**：畫面上顯示「Welcome, TestUser 👋」以及角色標籤「一般用戶」。

---

## [x] 【前端元素】管理員角色時顯示「管理後台」連結
**範例輸入**：`user` 為 `{ username: 'Admin', role: 'admin' }`
**期待輸出**：Header 導航列中顯示「🛠️ 管理後台」連結，角色標籤為「管理員」。

---

## [x] 【前端元素】一般用戶角色時不顯示「管理後台」連結
**範例輸入**：`user` 為 `{ username: 'User', role: 'user' }`
**期待輸出**：Header 導航列中「不顯示」管理後台連結。

---

## [x] 【Mock API】載入商品時顯示載入中狀態
**範例輸入**：商品 API 尚未回傳結果
**期待輸出**：畫面商品列表區塊顯示「載入商品中...」與 Spinner。

---

## [x] 【Mock API】成功載入商品後顯示商品卡片
**範例輸入**：商品 API 成功回傳商品陣列 `[{ id: '1', name: '商品A', description: '描述', price: 100 }]`
**期待輸出**：畫面不顯示載入中，並正確渲染出商品卡片包含名稱、描述及價格。

---

## [x] 【Mock API】API 回傳錯誤時顯示錯誤訊息
**範例輸入**：商品 API 回傳失敗 (例如 500)，錯誤訊息為「無法載入商品資料」
**期待輸出**：畫面不顯示載入中，並於商品區塊顯示錯誤訊息「無法載入商品資料」。

---

## [x] 【Mock API】API 回傳 401 時不顯示錯誤訊息
**範例輸入**：商品 API 回傳 401 Unauthorized
**期待輸出**：畫面不會設定 error (錯誤由 interceptor 處理)，商品列表維持無錯誤狀態。

---

## [x] 【function 邏輯】點擊登出按鈕時呼叫 logout 並導向 /login
**範例輸入**：使用者點擊「登出」按鈕
**期待輸出**：呼叫 `logout()`，並使用 `navigate('/login', { replace: true, state: null })` 進行路由導向。
