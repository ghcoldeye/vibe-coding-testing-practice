## [x] 【前端元素】渲染歡迎標題與文字
**範例輸入**：無
**期待輸出**：畫面上顯示「歡迎回來」與「請登入以繼續」文字，並顯示電子郵件、密碼輸入框與登入按鈕。

---

## [x] 【驗證邏輯】Email 格式錯誤時顯示錯誤訊息
**範例輸入**：Email 填寫 `invalid-email`，密碼填寫 `Valid1234`
**期待輸出**：按下登入時，Email 欄位下方顯示「請輸入有效的 Email 格式」且不呼叫 API。

---

## [x] 【驗證邏輯】密碼長度不足 8 碼時顯示錯誤訊息
**範例輸入**：Email 填寫 `test@example.com`，密碼填寫 `aB123`
**期待輸出**：按下登入時，密碼欄位下方顯示「密碼必須至少 8 個字元」且不呼叫 API。

---

## [x] 【驗證邏輯】密碼缺少英數混合時顯示錯誤訊息
**範例輸入**：Email 填寫 `test@example.com`，密碼填寫 `12345678` 或 `abcdefgh`
**期待輸出**：按下登入時，密碼欄位下方顯示「密碼必須包含英文字母和數字」且不呼叫 API。

---

## [x] 【Mock API】登入成功後顯示載入中並導向至 /dashboard
**範例輸入**：填寫正確的 Email `test@example.com` 與密碼 `Valid1234`，Mock login API 回傳成功
**期待輸出**：按下登入按鈕後，按鈕文字變為「登入中...」，接著導向至 `/dashboard`。

---

## [x] 【Mock API】登入失敗時顯示 API 錯誤訊息
**範例輸入**：填寫正確的 Email `test@example.com` 與密碼 `Valid1234`，Mock login API 拋出錯誤 (如：帳號或密碼錯誤)
**期待輸出**：API 回傳後，表單上方顯示對應的 API 錯誤訊息 (如「登入失敗，請稍後再試」或 API 回傳的 message)。

---

## [x] 【驗證狀態】若使用者已登入，自動導向 /dashboard
**範例輸入**：載入元件時，`isAuthenticated` 為 true
**期待輸出**：不顯示登入表單，直接導向至 `/dashboard`。

---

## [x] 【驗證狀態】若有過期訊息，顯示該錯誤並呼叫清除函式
**範例輸入**：載入元件時，`authExpiredMessage` 為「登入狀態已過期」
**期待輸出**：元件渲染後顯示錯誤訊息「登入狀態已過期」，並且呼叫了 `clearAuthExpiredMessage()`。
